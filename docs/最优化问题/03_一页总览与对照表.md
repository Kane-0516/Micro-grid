## 与 HOMER（一句话）

流程类似（先 PV 范围 → 再配储柴 → 全年仿真 → 比经济性）；实现不同（我们：MILP + 套数轴 + PyPSA LP；HOMER：多维 Search Space + 规则仿真）。

## 问题④ 与 MPC 跨领域（一句话）

**EMS 预测调度（④）** 与 **无人机/小车寻路** 同属 **MPC 范式**：预测未来 → 窗内优化 → 只执行第一步 → 滚动；时间尺度与物理模型不同，架构可对标。

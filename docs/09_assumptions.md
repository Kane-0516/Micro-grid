# Assumptions / 假设条件

| # | English | 中文 |
|---|---------|------|
| 1 | Bracket dimensions fixed at 28 m × 5.6 m (all models scale area by panel count, physical size unchanged) | 支架尺寸固定为 28 m × 5.6 m（所有型号按面板数缩放面积，物理尺寸不变） |
| 2 | Adjacent bracket spacing fixed at 10 ft (3.048 m), applies in all directions | 相邻支架间距固定为 10 ft（3.048 m），适用于所有方向 |
| 3 | Default diesel fuel efficiency 3.5 kWh/L (can be overridden per model) | 柴油发电效率默认 3.5 kWh/L（可按型号覆盖） |
| 4 | PV system efficiency 78% (includes inverter, line loss, temperature loss) | 光伏系统效率 78%（含逆变器、线损、温度损失） |
| 5 | Battery DoD 90%, cycle life per model specification | 电池 DoD 90%，循环寿命按型号 |
| 6 | Economic analysis default: 25 years, nominal discount rate 10%, inflation 2% | 经济分析默认 25 年，名义折现率 10%，通胀 2% |
| 7 | Default diesel price $0.95/L | 柴油价格默认 $0.95/L |
| 8 | NASA POWER data used for solar assessment (not field-measured) | NASA POWER 数据用于日照评估（非实测） |
| 9 | PyPSA simulation uses simplified solar model (sine curve + random cloud cover) | PyPSA 仿真使用简化光照模型（正弦曲线 + 随机云遮） |
